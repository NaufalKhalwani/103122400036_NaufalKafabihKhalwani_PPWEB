# Checklist tangkapan layar pengujian

Lingkungan penyusunan dapat menjalankan server dan memeriksa endpoint API (HTTP 200, 503, 201, dan 404), tetapi browser otomatis diblokir oleh kebijakan sistem. Karena itu screenshot UI asli harus diambil dari browser komputer praktikan; folder ini disediakan untuk menyimpannya.

Simpan minimal tangkapan layar berikut di folder ini:

1. `01-soal-01-pengumuman.png` — Soal 01 setelah pengumuman dimuat.
2. `02-soal-01-fetch-counter.png` — Soal 01 setelah mock dimuat, catatan terisi, dan hitungan bernilai 3.
3. `03-soal-02-get.png` — Soal 02 dengan tiga peserta pada skenario Berhasil.
4. `04-soal-02-post.png` — response POST Rina Praktikan, HTTP 201, ID 101, simulated true.
5. `05-soal-02-error.png` — skenario Error HTTP (HTTP 503) atau Timeout.

Jangan membuat atau mengedit gambar seolah-olah merupakan hasil pengujian asli. Ambil langsung dari browser setelah menjalankan `JALANKAN.bat`.
