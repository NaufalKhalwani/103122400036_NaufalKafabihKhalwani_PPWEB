# Pengumpulan Praktikum Modul 07 — AJAX dan Konsumsi API

## Isi paket

- `latihan-praktikan/soal-01/`: portal informasi praktikum menggunakan XMLHttpRequest dan Fetch.
- `latihan-praktikan/soal-02/`: aplikasi registrasi React menggunakan Axios GET/POST, `useState`, dan `useEffect`.
- `bukti-pengujian/`: tangkapan layar aplikasi dan skenario uji yang dijalankan.
- `LAPORAN_MODUL_07.md`: penjelasan implementasi dan hasil pengujian.

## Cara menjalankan

1. Ekstrak ZIP ini ke folder biasa.
2. Pastikan Node.js versi 18 atau lebih baru sudah terpasang.
3. Jalankan `JALANKAN.bat` (Windows), atau buka terminal di folder utama lalu jalankan `node server.cjs`.
4. Buka `http://127.0.0.1:3007/latihan-praktikan/soal-01/` untuk Soal 01.
5. Buka `http://127.0.0.1:3007/latihan-praktikan/soal-02/` untuk Soal 02.
6. Biarkan terminal server tetap berjalan selama pengujian.

Tidak perlu `npm install`; React, ReactDOM, Axios, dan Babel sudah tersedia pada folder `vendor` dari paket praktikum. JSONPlaceholder membutuhkan koneksi internet.
